# Rahma Edu Hub — Professional Report Card

This upgrade builds on the existing Academic Records, Exam Timing, Teacher Assignment, Marks & Results, Parent/Family, and Class Remarks features.

## What was added
- Professional print-ready report card with Rahma Junior logo and school branding.
- Student name, admission number, class and report date.
- Select which exam/assessment to print as a report card.
- Subject-by-subject marks, percentage, grade and teacher remark.
- Automatic average and overall grade for the selected assessment.
- Class Teacher and Headteacher signature areas.
- Print layout hides portal controls and produces a clean report-card page.

## Database
No new SQL migration is required. This uses the existing academic records.

## Test
1. Teacher enters and saves marks.
2. Open Academic Records.
3. Select a student.
4. Select the exam under "Report card".
5. Click "Print professional report card".
